Project Name: Cyber Cryptography Tool (Text Encryptor & Decryptor)
Overview:
This project is a desktop application developed in Python using the tkinter library. It demonstrates the core concepts of Cryptography—one of the fundamental pillars of Cybersecurity—by allowing users to secure plain text messages into unreadable ciphertext and restore them using a numeric secret key.
Key Features:
• Text Encryption & Decryption: Protects sensitive messages using character-shifting logic (Symmetric Encryption concept).
• Input Validation & Error Handling: Built-in try-except mechanisms to prevent application crashes from invalid key inputs.
• File Export: Allows users to save encrypted messages directly into a .txt file (secret_output.txt) for secure sharing.
• User-Friendly Dark Mode UI: Designed with a clean, modern interface for intuitive usability.
What I Learned:
Through building this tool, I gained practical experience in translating theoretical cybersecurity concepts (Confidentiality and Encryption) into functional software, handling user input errors, and designing graphical user interfaces (GUI) in Python.
